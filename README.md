# כלי סימון תמונה V1.9.1 | Single Image Annotation Studio

אפליקציה סטטית של מעבדת אליהו לסימון תמונה בודדת, קישור למונחים וניתוח הרשת שנוצרת מן התיוגים באותה תמונה. היא פועלת גם ב־GitHub Pages וגם מקומית ללא שרת. מקור הטבלאות המקוון הוא **Google Sheets מקורי בשם bar_research_data_registers_v2**. באתר, רענון הערכים קורא ישירות את הטאבים; אפשר גם לטעון קובץ XLSX מקומי.

כל פרויקט מייצג תמונה אחת בלבד. תוצר הנתונים הראשי הוא CSV מלא ודו־לשוני של אותה תמונה: רשומת החומר, פרטי קובץ התמונה, הסימונים, הגאומטריה והמזהים הסמנטיים. חבילת ZIP נפרדת שומרת את התמונה, JSON-LD והיסטוריית הגרסאות לצורך המשך עריכה. מערכת חיצונית או מסד נתונים יוכלו בעתיד לקלוט את קובצי ה־CSV של התמונות השונות ולנהל אותם יחד.

## הפעלה מקומית ללא GitHub

1. חלצו את כל הקבצים לתיקייה אחת.
2. פתחו את `index.html` בדפדפן עדכני.
3. לחצו `טעינת Excel מקומי` ובחרו XLSX שבו הטאבים הדו־לשוניים.
4. בחרו חומר, העלו תמונה והתחילו לתייג.

אין צורך בהתקנה או בחיבור רשת. קורא ה־XLSX נמצא בקובץ `xlsx-reader.js`, ורכיב פתיחת הדחיסה המקומי נמצא ב־`pako_inflate.min.js`.

הקובץ המקורי שסופק הוא תבנית תקינה: טאבי החומרים, המונחים והקשרים מכילים כותרות אך עדיין אינם מכילים רשומות. לכן לאחר טעינתו הכלי מציג חיווי שהקובץ נטען בהצלחה ושעדיין אין רשומות חומרים.

## פרסום ב־GitHub Pages

1. חלצו את חבילת V1.9.1 והעלו **את כל התוכן** לשורש המאגר: במיוחד `index.html`, התיקייה `scripts/` והתיקייה הנסתרת `.github/workflows/`. אין להעלות את תיקיית V1.9.1 כמפלס נוסף בתוך המאגר. יש לשמור את שאר קובצי האפליקציה לצד `index.html`.
2. ב־Settings → Pages → Build and deployment השאירו Source כ־**GitHub Actions**. אין צורך בחשבון GitHub או בהרצת Action מצד בר.
3. ב־Google Sheets המקורי פתחו Share ואמתו שאפשר לפתוח את קישור העריכה בחלון פרטי ללא כניסה לחשבון. להרשאת קריאה דרך ממשק Google Visualization נדרשת צפייה ציבורית (Anyone with the link → Viewer); קישור `pubhtml` בפני עצמו אינו מאמת את הרשאת הקריאה לממשק הנתונים. אם הגיליון רגיש, אין להגדיר הרשאה כזאת; יש להשתמש בקובץ Excel מקומי או בשירות נתונים מורשה.
4. רעננו את האתר; כאשר הקריאה הישירה מצליחה יופיע `נתונים עדכניים מ־Google Sheets` והמונחים יופיעו לצד התמונה. אחרי שינוי בגיליון לחצו `רענון נתונים` בתוך האפליקציה. העמוד בודק שינויים גם אוטומטית מדי דקה כשהוא גלוי. אם טאב המונחים לא נקרא, מוצגת כעת הודעת שגיאה מפורשת; אפשר לטעון Excel מקומי כגיבוי.

המערכת קוראת את מזהה הגיליון `1SA4BpAIzvyGni1vWtfShJsrmiT4e6NsNKOUAawrg-Jg`. המשיכו לערוך קובץ זה; המרה או העתקה נוספים ייצרו מזהה חדש המחייב עדכון האפליקציה.

## מקורות הטבלאות

הקישור לגיליון Google Sheets המקורי מוטמע ב־`index.html`. הכלי קורא את הטאבים הקיימים בשמותיהם המדויקים:

1. רישום חומרים | Materials register
2. ערכי בחירה לחומרים | Material controlled values
3. רישום מונחים | Terms register
4. ערכי בחירה למונחים | Term controlled values
5. רישום קשרים ושלשות | Relations and triples register
6. ערכי בחירה לקשרים | Relation controlled values
7. רישום מושגים | Concepts register
8. ערכי בחירה למושגים | Controlled concept values

האפליקציה אינה כותבת לגיליון. דפדפן המשתמש קורא את הנתונים בזמן אמת בממשק Google Visualization של הגיליון הציבורי. צילום מצב `data/register.json` שנוצר ב־GitHub Actions משמש רק גיבוי; כישלון יצירתו אינו חוסם את פרסום האפליקציה. קובצי Excel מקומיים עם שמות הטאבים מן הגרסה הקודמת ממשיכים להיטען.

## מהלך עבודה

1. במסך ההקמה בחרו חומר לפי מזהה, הזינו מזהה ידני או התחילו מתמונה שטרם נרשמה.
2. העלו תמונת מקור. לאחר הטעינה מסך בחירת החומר נעלם ואינו תופס מקום בסביבת התיוג.
3. בחרו מונח מן הרשימה הקבועה לצד התמונה ובחרו נקודה, מלבן או מצולע. אפשר להזיז ולערוך סימון קיים. לכל סימון מוצג מספר זהה על התמונה ובמרשם הסימונים הצמוד לה; בחירה או מעבר עכבר מדגישים את אותו מופע בשני המקומות. מספרים אלה הם חיווי מסך בלבד, ואינם מחליפים את מזהי המופעים השמורים בקבצים.
   בכל תג מופיע האם הסימון משויך למושג, כולל מזהה המושג אם ישנו, או שהוא משויך למונח בלבד; לצדו מוצג בנפרד מספר הקשרים עם סימונים אחרים. היעדר קשר בין סימונים אינו שולל את שיוך המונח או המושג. כשבוחרים סימון קיים, אזור העריכה מציג את התג שלו; מונח שייבחר אחר כך ברשימה מיועד לסימון הבא, או לשינוי השיוך רק בלחיצה על ״שיוך המונח לסימון הנבחר״. רשומות המושגים הראשוניות הן מועמדות לבדיקה.
4. בטאב `תיוגים ורשת` בחרו שני סימונים שונים ואת סוג היחס מרשימת הערכים שבטאב `ערכי קשרים | Relation values`. לחצו `יצירת קשר`. הקשר נשמר כגרסה ומופיע ברשת וב־CSV. אפשר למחוק קשר בנפרד. טאב `קשרים | Relations` בגיליון משמש לרשומות קשר קיימות, ואינו אוצר סוגי היחסים. מחיקת סימון מתוך מסך התיוג מבקשת אישור ומוחקת גם את קשריו.
5. בטאב `נתונים` בדקו את ה־CSV הקנוני, הצמתים, הקשתות והיסטוריית הגרסאות.
   בטאב `אודות` יש מדריך דו־לשוני מפורט על ההבדל בין מופע, מונח ומושג, היחסים ביניהם, המידע שנשמר וכללי החלטה לקטלוג עקבי; החיוויים עצמם זמינים כבר בזמן התיוג.
6. הורידו `CSV מלא` כתוצר המחקרי ו־`פרויקט לעריכה` כדי לשמור תמונה והיסטוריית גרסאות.

כפתור `רענון נתונים` קורא את הערכים ישירות מהגיליון החדש ומרענן את רשימות הבחירה תוך שמירה על התמונה והתיוגים הפתוחים. העמוד מבצע את אותה בדיקה אוטומטית מדי דקה כשהוא גלוי. קובץ Excel מקומי נטען מחדש באמצעות `טעינת Excel מקומי`; קובץ מקומי אינו מתעדכן אוטומטית. אם ה־Google Sheet אינו מאפשר קריאה ציבורית באמצעות Google Visualization, תופיע הודעת כשל או שיופעל צילום המצב הישן, אם הוא קיים. אין לטעון שקריאה ישירה עובדת עד לבדיקה בדפדפן ללא כניסה לחשבון.

תיקון V1.9.1: בקשת Google Visualization קוראת את כל הגיליון, כולל שורת הכותרת המקורית בשורה 4, במקום להסתמך על הכותרת שהשירות מסיק ומחזיר. האפליקציה אינה מכריזה על טעינה מוצלחת אם היא לא מזהה תוויות מונחים.

המערכת אינה יוצרת מונחים או קשרים חדשים במהלך התיוג. אוצר המונחים מנוהל בקובץ המקור וטוענים אותו מחדש למערכת. קשרים שכבר קיימים בפרויקט או בקובץ נתונים של אותה תמונה נשמרים, מוצגים ברשת ומיוצאים ללא שינוי.

במשטח התיוג אפשר להגדיל ולהקטין את התמונה בין 50% ל־400%; לחיצה על אחוז הזום מחזירה להתאמה למסגרת. `איפוס התמונה` מוחק מן הדפדפן את התמונה הפעילה, הסימונים והיסטוריית הגרסאות ומחזיר למסך ההקמה. קבצים שכבר הורדו אינם נמחקים.

אפשר להתחיל גם מתמונה ששמה אינו מופיע עדיין בעמודה `שם קובץ מקומי | Local filename`. במקרה כזה הכלי מסמן אותה כ־`טרם נרשמה | Not yet registered`, מאפשר לתייג אותה, ושומר את הסטטוס ב־CSV וב־JSON-LD. אם שם הקובץ תואם לרשומת חומר, הכלי מציג את Material ID שנמצא.

כפתורי `עברית` ו־`English` בכותרת מחליפים את שפת הממשק ואת כיוון התצוגה. ערכי המחקר והמזהים עצמם נשארים כפי שהם בקובץ המקור.

אפשר לפתוח מחדש ZIP, JSON-LD או CSV מלא. ZIP שומר את התמונה ואת כל הגרסאות. CSV משחזר את הנתונים והרשת; כדי להמשיך בסימון חזותי יש לצרף מחדש את קובץ התמונה, והכלי מאמת את חתימת SHA-256.

## מודל ותקנים

- W3C Web Annotation ו־SVG Selector עבור סימונים מרחביים.
- JSON-LD עבור הפרויקט הסמנטי.
- W3C PROV-O עבור גרסאות, זמן, מתעד והפניה לגרסה קודמת.
- טבלת long-form עבור `knowledge.csv`: חומר, תמונה, סימון וקשר כרשומות נפרדות עם מזהים יציבים. הצעות ישנות מפרויקטים קודמים נשמרות לצורכי תאימות בלבד.
- `project.schema.json` מתאר את `project.jsonld`, לרבות סטטוס רישום התמונה.
- `CSV_DATA_DICTIONARY.md` מתעד את ה־CSV ואת כללי בניית הרשת.

## קבצים בחבילת פרויקט

- `knowledge.csv` — תוצר טבלאי קנוני שממנו אפשר לבנות את הרשת; כולל מזהי סימון ומופע חזותי נפרדים וצילום מצב של פרטי המושג בזמן התיוג.
- `project.jsonld` — מצב עריכה סמנטי והיסטוריית גרסאות.
- `annotations.csv`, `relations.csv` — תצוגות מצומצמות לתאימות עם הרישומים הקודמים.
- `assets/` — תמונת המקור, אם נטענה.

חבילת ZIP נוצרת ללא דחיסה כדי שאפשר יהיה לפתוח אותה בדפדפן ללא תלות חיצונית. פתיחת ZIP נתמכת עבור חבילות שנוצרו בכלי.
