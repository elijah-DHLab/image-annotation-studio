# כלי סימון תמונה V1.9.2 | Single Image Annotation Studio

אפליקציה דו־לשונית של מעבדת אליהו לתיוג תמונה בודדת. המונחים וסוגי הקשרים מגיעים מהגיליון. הסימונים, הקשרים והגרסאות נשמרים בפרויקט וניתנים להורדה, ולא נכתבים לגיליון.

## החלפת הגרסה בגיט

1. לפני ההחלפה, שמרו כל פרויקט פתוח באמצעות הורדת חבילת הפרויקט (ZIP).
2. חלצו את החבילה והעתיקו את כל תוכנה לשורש המאגר image-annotation-studio, במקום קובצי האפליקציה הקודמים. אין להעלות רק את ה־ZIP, ואין ליצור תיקיית גרסה נוספת סביב הקבצים.
3. חשוב להעלות גם את data/, את scripts/ ואת .github/workflows/sync-sheet.yml. הקבצים index.html, xlsx-reader.js, pako_inflate.min.js והלוגו נשארים בשורש.
4. ב־Settings → Pages השאירו את מקור הפרסום על GitHub Actions. המתינו לסיום מוצלח של הריצה שנוצרה בעקבות ההעלאה. אין צורך שבר תיכנס לגיט.
5. פתחו את האתר ורעננו באמצעות Ctrl+Shift+R. בדקו שבכותרת מופיע V1.9.2.
6. העלו תמונה. בחבילה זו אמורים להופיע 8 מונחים. הודעת המקור נמצאת בכותרת ונשארת גלויה גם לאחר העלאת התמונה.

אם ריצת הסנכרון בגיט נכשלת, הגרסה החדשה לא תפורסם. יש לקרוא את השגיאה בשלב Read current public Excel from Drive and validate tabs; הגרסה שכבר פורסמה אינה נמחקת. אין להתייחס לפרסום האתר כהוכחה שהסנכרון הצליח.

## מקור הנתונים וסנכרון

הקישור מוטמע מראש:
https://docs.google.com/spreadsheets/d/1SA4BpAIzvyGni1vWtfShJsrmiT4e6NsNKOUAawrg-Jg/edit

האפליקציה מבקשת את שמות הלשוניות האמיתיים, ולא את כותרות התאים:

- חומרים | Materials
- ערכי חומרים | Material values
- מונחים | Terms
- ערכי מונחים | Term values
- קשרים | Relations
- ערכי קשרים | Relation values
- מושגים | Concepts
- ערכי מושגים | Concept values

בעת פתיחת האפליקציה מוצג מיד עותק הנתונים המצורף, שמקורו בקובץ שסופק להכנת הגרסה. באתר מתבצעת גם בקשה ישירה ל־Google Sheets. הצלחתה מחליפה את העותק ומציגה Google Sheets מחובר עם מספר המונחים וסוגי הקשרים. כפתור רענון נתונים קורא שוב מגוגל בלי לפתוח GitHub. בדיקה אוטומטית מתבצעת מדי דקה כשהעמוד גלוי וגם בחזרה ללשונית. אין הבטחה לעדכון מיידי בכל הקלדה, משום שהזמינות והמטמון של Google עשויים לעכב את הקריאה.

עותק גיבוי אינו אישור לנתונים חיים. אם גוגל אינו נגיש, הנתונים שכבר נקראו נשארים זמינים, והמערכת מציגה אזהרה. אין מחיקה של סימונים או החלפה של נתונים חיים בעותק ישן בעקבות כשל. data/register.json הוא גיבוי קריא; data/register-bundled.js מאפשר גם אתחול ללא שרת. ה־Action מעדכן את שניהם מאותו גיליון בעת פרסום ובבדיקות המתוזמנות. מועד יצירת עותק אינו מועד העריכה האחרון בגיליון.

קריאה ישירה של הגיליון דורשת הרשאת צפייה ציבורית. אין לשנות שוב הרשאות שכבר תקינות. אם מבטלים פרסום ציבורי, יש להשתמש ב־Excel המקומי או לפתח שירות נתונים מורשה.

## עבודה מקומית

חלצו את כל החבילה ופתחו index.html. שמונת המונחים המצורפים זמינים גם ללא רשת. כדי להשתמש בנתונים אחרים או מעודכנים, בחרו טעינת Excel מקומי. טעינה מקומית תקינה מפסיקה את הרענון האוטומטי מגוגל; לחיצה מפורשת על רענון נתונים מאפשרת חזרה למקור המקוון. בקשה מקוונת שהתחילה לפני טעינת Excel לא תדרוס את הבחירה המקומית.

## מה נמצא בקובץ שסופק

8 מונחים, 7 רשומות מושגים ו־14 סוגי קשרים. טבלת החומרים וטבלת הקשרים אינן מכילות רשומות. הדבר אינו חוסם העלאת תמונה שלא נרשמה או יצירת קשרים בפרויקט.

המונח TERM-0008 / Genitalia - Male מפנה אל CON-0008, שאינו קיים כרגע בטבלת המושגים. המערכת שומרת את המזהה המקורי ומאפשרת להשתמש במונח, אך מציינת שקיימת הפניה למושג שטרם נרשם. היא אינה ממציאה עבורו הגדרה. הקובץ והגיליון המקוריים לא שונו.

## תיוג, קשרים וייצוא

בחרו מונח מן הרשימה לצד התמונה, ואז סמנו נקודה, מלבן או מצולע. בחירת סימון מקשרת בין המספר שעל התמונה לתג שבצד. אפשר להזיז, לשנות שיוך ולמחוק סימון. מחיקה דורשת אישור, מסירה גם קשרים המחוברים לסימון ונרשמת בהיסטוריית הפרויקט.

לאחר יצירת שני סימונים, עברו אל תיוגים ורשת, בחרו סימון מקור, סימון יעד וסוג קשר מן הרשימה, ולחצו יצירת קשר. הרשימה מגיעה מהעמודה יחס | Predicate בלשונית ערכי קשרים | Relation values, ולא מטבלת טענות הקשר הריקה.

CSV כולל את נתוני התמונה הבודדת, הסימונים, מזהי המונחים והמושגים, הקשרים והגאומטריה היחסית. חבילת הפרויקט כוללת גם JSON-LD, את התמונה והיסטוריית הגרסאות. אפשר לטעון חבילה קיימת להמשך עבודה. הקשר בין מונח, מושג ומופע מוסבר בטאב אודות. ראו גם DATA_MODEL.md ו־CSV_DATA_DICTIONARY.md.

## בדיקות שבוצעו

הבדיקות המקומיות משתמשות בקורא ה־XLSX האמיתי של האפליקציה ובקובץ V2 המצורף, ללא שינוי שמות הלשוניות. הן בודקות טעינת כל הלשוניות, יצירת שמונת כפתורי המונחים, 14 סוגי הקשרים, קריאת JSONP מדומה בשמות הנכונים, החלפת נתונים ברענון, שמירת פרויקט קיים, שגיאת רשת, תשובה עם כותרת שגויה, טעינה מקומית במקביל לבקשת רשת, יצירת סימונים וקשר, מחיקה עם הקשרים, ייצוא CSV ו־JSON-LD ותוויות באנגלית.

בדיקות אלה אינן בדיקת דפדפן מלאה ואינן מאמתות זמינות רשת חיה של Google או את הפריסה באתר GitHub Pages. לאחר הפרסום יש לוודא גם את הודעת Google Sheets מחובר באתר.

להרצת הבדיקות, עם Node ו־Python וספריית openpyxl:

```sh
python scripts/sync_workbook.py --file /path/to/bar_research_data_registers_v2.xlsx --output data/register.json
node scripts/test_app.cjs /path/to/bar_research_data_registers_v2.xlsx
```

בדיקות הקובץ המצורף מקבעות את ספירות ה־V2 ששימש להכנת הגרסה. שינוי מכוון של נתוני המקור ידרוש התאמת ציפיות הבדיקה, לא שינוי באפליקציה.
